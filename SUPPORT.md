# 🛟 Support

- 📖 **Documentation**: most Python projects have one on Read the Docs, linked from their README.
- ❓ **Question about using a project**: open an issue with the "Question" form.
- 🐛 **Bug or idea**: open an issue with the matching form, see [CONTRIBUTING.md](CONTRIBUTING.md).
- 🔒 **Security problem**: see [SECURITY.md](SECURITY.md), never a public issue.

These projects are maintained on free time: answers can take a few days. ☕
